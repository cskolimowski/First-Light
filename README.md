# First Light

A tiny original side-scrolling browser platformer built as a GitHub collaboration experiment.

## Play
Download the repository, open `index.html` in a modern browser, and play immediately. No install or build step is required.

## Controls
Arrow Left / Right or A / D to move. Space, W, or Arrow Up to jump. R restarts the level.

## Goal
Collect stars, jump on roaming enemies, cross the gaps, and reach the glowing beacon at the far right of the level.

The game design notes live in `docs/GAME_DESIGN.md`.
